# Air Quality API

## Description

Ce projet est une API RESTful qui fournit des données de qualité de l'air en utilisant Spring Boot. L'application permet de récupérer des informations sur la qualité de l'air à partir de différents capteurs et d'effectuer des analyses.

## Fonctionnalités

- Ajouter des capteurs de qualité de l'air.
- Enregistrer les mesures des capteurs.
- Consulter les mesures enregistrées.
- Support de base de données H2 en mémoire pour le stockage des données.
